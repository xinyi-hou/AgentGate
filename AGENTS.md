# Repository Instructions

- After completing any task that changes repository files, validate the changes, commit all intended updates with a concise commit message, and automatically push the current branch to `origin`.
- Do not wait for a separate push request after a successful commit.
- Stage only files intended for the current task. Preserve unrelated user changes.
- Never use force push or rewrite published history unless the user explicitly requests it.
- If a push is blocked by authentication, remote changes, or branch protection, report the exact blocker instead of bypassing it.
